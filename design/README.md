# IPV6 Ctrl · Android 应用设计

2026-10-15：产品方向为 **LSPosed 模块 + 可从桌面独立打开的 Android 应用**。此前排除 hook 的主机测试计划已被本次要求取代。

## 本轮交付范围

- 由网页 Gemini **4 Argon** 制作中文高保真设计，通过现有 Chrome CDP 会话操作。
- 三个主页面：总览、作用范围、诊断；补齐未激活、待生效和失败状态，提供浅色与深色示例。
- 默认一个 APK 同时包含模块与桌面应用入口，包装方式仍可在实现时调整。
- 界面分别表达目标策略、模块执行结果和实际检测结果；检测失败显示“未确认”。
- 图中作用范围和状态均为设计示例，不能视为已实现的任意应用级 IPv6 隔离或完整内核覆盖。

## 视觉方向（用户最新要求）

- 使用原生 SVG 矢量与文本绘制，保持图层可编辑。
- 软件层级与操作逻辑清晰，以分区、列表、流程状态和主操作组织页面，避免卡片平铺。
- 配色方案由 Gemini 主导；颜色表达选择、未保存、待生效、成功与失败，同时保留文字和图标提示。
- 图标统一风格；可选单一开源方案，采用时记录来源与许可。

## 交付格式

[打开可编辑 Figma 稿](https://www.figma.com/design/ZIsLnq1wA0ygLN6qj74Wlg)

- `argon-main.svg`：Gemini 4 Argon 按最新反馈重绘的三张主屏，单屏 412×915；原生矢量分组，110 个可编辑文本节点。
- `preview.png`：从 Figma 画布直接截取的预览，未包含账号或浏览器界面；完整尺寸以 SVG 为准。
- `LUCIDE-LICENSE`：图标来源 [Lucide](https://lucide.dev/license)，包含 ISC 与衍生 Feather 图标的 MIT 许可；SVG 的 metadata 同时保留许可。

已通过 CDP 导入 Figma，并检查页面分组、文字可编辑性、中文显示及重载后的云端保留情况。首次导入将字体错误映射为 Noto Sans；源稿统一为 Figma 可用的 `Noto Sans SC` 后重新导入。

Gemini 主导布局、配色、图标与文案；本地收尾仅清理按钮中的 `48dp` 实现标注、调整对应文字居中、修正未经验证的权限描述并补充许可与字体兼容处理。初版草稿保留在 Git 提交 `8da04a5`，当前目录仅保留新版。
