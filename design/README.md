## 前版设计 · 2026-10-15

2026-10-15：产品方向为 **LSPosed 模块 + 可从桌面独立打开的 Android 应用**。此前排除 hook 的主机测试计划已被本次要求取代。

## 本轮交付范围

- 由网页 Gemini **4 Argon** 制作中文高保真设计，通过现有 Chrome CDP 会话操作。
- 三个主页面：总览、作用范围、诊断；补齐未激活、待生效和失败状态，提供浅色与深色示例。
- 默认一个 APK 同时包含模块与桌面应用入口，包装方式仍可在实现时调整。
- 界面分别表达目标策略、模块执行结果和实际检测结果；检测失败显示“未确认”。
- 图中作用范围和状态均为设计示例，不能视为已实现的任意应用级 IPv6 隔离或完整内核覆盖。

## 视觉方向（用户最新要求）

- 使用原生 SVG 矢量与文本绘制，保持图层可编辑。
- 软件层级与操作逻辑清晰，以分区、列表、流程状态和主操作组织页面，避免卡片平铺。
- 配色方案由 Gemini 主导；颜色表达选择、未保存、待生效、成功与失败，同时保留文字和图标提示。
- 图标统一风格；可选单一开源方案，采用时记录来源与许可。

| 操作语义 | 主色 |

操作路径：选择目标与策略 → 保存配置 → 按提示重启目标 → 手动检测。未激活时锁定策略操作并提供引导；保存失败保留原配置，实际网络状态仍需检测。恢复默认需按提示重启目标，不宣称即时解除所有连接影响。真实 LSPosed 注入范围仍须在管理器中确认，设计中的目标选择不代表已实现作用域同步。

当前交付为六张静态高保真界面，不含可点击原型连接或 Android 实现。图中功能与诊断结果均为设计示例，不代表模块已实现或实机验收通过。

设计阶段不改变设备网络设置。现有 daemon/WebUI 稳定性工作独立保留在原功能分支中。
